'''Pondering''' is an in-game guide system that allows the player to quickly get information about Create blocks.

The pondering screen shows an example contraption that explains the functions of the block.
[[File:Windmill Bearing Ponder.mp4|thumb|270px|The Ponder scene for a [[Windmill Bearing]].]]

==Usage==
The full Ponder Index can be accessed through the Create menu by clicking the {{ItemLink|Engineer's Goggles}} icon in the pause menu.

An item can be Pondered by hovering over it in the inventory and holding {{ctrl|forward}} ("W" by default) until the bar below the item is filled up. This displays an animated infographic about the item being pondered. 
===Keybinds===
The keybinds for ponder are the same as those for certain player actions.
* '''Q''' - Activate Identify mode. This pauses the current ponder scene. Hovering over Create elements shows the name of the block and gives the option to ponder those elements.
* '''S''' - Restart the current animation.
* '''A''' or '''D''' - Go backwards or forwards a scene, if available. 
* '''E''' - Close the animation.

Comfy Reading does not currently have a keybind, but can be enabled by tapping the button in the bottom right. This slows down the entire animation to help read the text boxes. 
===Navigation===
While Pondering, similar or relevant machines can be viewed by clicking the icon to the left or activating identify mode and holding '''W''' over a visible component. After moving away from the initially pondered item, the option to "Think Back" can be found at the bottom left. The player can skip to specific parts of an animation by clicking different sections of the gray bar at the bottom.

===Ponder Categories===
The categories ponders are sorted into in-game.
*{{ItemLink|Cogwheel|}} Kinetic Blocks - Components which help relaying [[Rotational Force]] elsewhere
*{{ItemLink|Water Wheel|}} Kinetic Sources - Components which [[:Category:Generators|generate]] [[Rotational Force]]
*{{ItemLink|Mechanical Press|}} Kinetic Appliances - Components which make use of [[Rotational Force]]
*{{ItemLink|img=Fluid Pipe|:Category:Fluid Systems|Fluid Manipulators}} - Components which help relaying and making use of Fluids
*{{ItemLink|:Category:Item Transportation|img=Chest|Item Transportation}} - Components which help moving items around
*{{ItemLink|:Category:Logic Components|Logic Components|img=Redstone Dust}} - Components which help with Redstone Engineering
*{{ItemLink|:Category:Creative Only|Creative Mode|img=Creative Crate}} - Components not usually available in Survival Mode
*{{ItemLink|:Category:Movement Anchors|Movement Anchors|img=Mechanical Piston}} - Components which allow the creation of moving [[Contraption]]s, animating an attached structure in a variety of ways.
*{{ItemLink|:Category:Movement Actors|Contraption Actors|img=Mechanical Harvester}} - Components which expose special behavior when attached to a [[Contraption]].
*{{ItemLink|:Category:Block Attachment Utility|Block Attachment Utility|img=Super Glue}} - Tools and Components used to assemble structures moved as an animated [[Contraption]].
*{{ItemLink|:Category:Railway Equipment|Railway Equipment|img=Train Track}} - Components used in the construction or management of [[Train]] contraptions
*[[File:Clipboard.png|24x24px]][[:Category:Recent Changes|Recent Changes]] - Components that have been added or changed significantly in recent versions of create
