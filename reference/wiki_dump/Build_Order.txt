Many of the new items introduced by the Create mod are constructed in part with other Create items. For example, a [[Shaft]] requires you to have first made [[Andesite Alloy]]. The table below categorizes the Create items into levels corresponding to the order in which items must be built. Building an item at level four will require one or more items from level three and potentially items from lower build levels as well as native Minecraft items. The asterisked items in the first column are used as components for other Create items at higher build order levels. 

The table below does not include all of the Create food or building material items. Items which differ only in appearance are grouped (ex. colored valve handles are not listed separately.)

Tip: To quickly find an item, press Ctrl+f and type the name.
